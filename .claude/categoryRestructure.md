# 카테고리 재정리안 (초안 — 아직 미승인, 코드/DB 변경 없음)

> 목적: 지금 카테고리 9개 + 소분류들을 살펴보니 "기타" 카테고리의 소분류 대부분이 이미 있는 다른 전용 카테고리와 내용이 겹친다. 이번에 한 번에 정리한다. 아이콘은 사용자가 Figma에서 직접 그려서 교체할 예정이므로, 이 문서는 **아이콘 스펙 + 최종 카테고리/소분류 구조**를 확정하는 용도.

## 2. 중복 발견

"기타(etc)"의 소분류 5개 중 **4개가 이미 전용 카테고리와 겹침**:

| 기타(etc)의 소분류 | 겹치는 전용 카테고리 |
| --- | --- |
| 여가/취미 | 여가·문화 > 취미 |
| 병원/의료 | 건강 > 병원, 약국 |
| 경조사 | 경조사·비정기 > 경조사 (완전 동일 문구) |
| 통신비 | 주거·통신 > 통신비 (완전 동일 문구) |
| 송금 | 금융 > 송금 (완전 동일 문구) |

→ 기타 카테고리가 사실상 "아직 전용 카테고리로 안 옮겨진 예전 소분류들의 잔재"인 상태. 5개 전부 겹친다.

추가로 사용자가 지적한 것: **구독서비스**가 지금 쇼핑에만 있는데, 넷플릭스/통신 요금 성격상 주거·통신에도 있어야 함.

## 3. 제안

### 3-1. 기타(etc) 소분류를 비운다 (추천)
5개 소분류를 전부 삭제. 이미 전용 카테고리가 있으므로 갈 곳 없는 지출이 생기면 그때 새 소분류를 추가하면 됨. 카테고리 자체(기타)는 남겨둠 — "미분류"(카테고리가 삭제됐을 때 자동으로 뜨는 상태, `UNCATEGORIZED_META`)와는 다른 개념이라, 사람이 판단해서 넣는 진짜 잡동사니용 칸은 하나 있는 게 나음.

- 대안: 기타 카테고리 자체를 없앤다 — 비추천. "미분류"는 카테고리 삭제로 인해 자동으로 생기는 상태라, 사람이 의도적으로 고를 수 있는 잡동사니 칸이 없어지면 오히려 매번 애매한 지출마다 새 카테고리를 만들게 됨.

### 3-2. 구독서비스는 주거·통신으로 이동 (쇼핑에서는 제거)
쇼핑에 남겨두면 "구독서비스"가 두 카테고리에 또 겹치게 됨. 지금 쇼핑>구독서비스로 찍힌 기존 거래 3건(ANTHROPIC* CLAUDE SUB, 네이버플러스멤버십, 한국정보인증주식회사)은 주거·통신>구독서비스로 재분류 필요.

### 3-3. 식비 > 카페 분리 — **확정**
새 카테고리 `cafe`(카페) 추가, 소분류는 일반카페/디저트카페/빵집·베이베리 3개. 업체명이 아니라 유형으로 나눈 이유: 소분류는 자유입력이 아니라 픽리스트(`categoryPicker.tsx`)라서 업체명 단위로 가면 갈 때마다 목록이 늘어남 — 업체명 매칭은 나중에 만들 "소분류 상세" 계층(`개인첨부/고정지출_예산_재설계안.md` Phase 3)에서 다룬다.
- 아이콘: 사용자가 Figma에서 손그림으로 제작 예정. 그 전까지는 `EtcIcon`을 임시로 씀(`src/constants/categories.ts`의 `cafe` 항목) — 도착하면 `CafeIcon` 컴포넌트만 추가하고 `Icon: EtcIcon` → `Icon: CafeIcon`으로 한 줄만 바꾸면 됨(DB 변경 없음)
- 색상: `LedgerColors.cafe`(`#C9967A`, 커피색 계열) 신규 추가
- 기존 식비>카페 거래는 카페>일반카페로 일괄 이동(과거 데이터엔 일반/디저트 구분이 없었음) — 디저트카페·빵집이었던 특정 건은 이동 후 수동으로 소분류만 변경

## 5. 아이콘 스펙 (Figma 작업 참고용)

기존 아이콘(`src/components/icons.tsx`)이 따르는 규칙:
- viewBox `0 0 20 20`
- `stroke` 기반 선화, `strokeWidth 1.7`, `fill="none"`
- 손그림 느낌(완벽한 직선/원보다 살짝 불규칙한 획)
- 색은 아이콘 자체에 넣지 않고 `LedgerColors`의 카테고리별 hex를 배경 원에 씀 — 아이콘 선 자체는 흰색/단색 한 가지

이번 재정리안대로면 **구조 변경만으로는 새 아이콘이 필요 없음** (기존 9개 카테고리 아이콘 그대로 재사용). 카페 분리(3-3)를 같이 하기로 하면 컵 모양 아이콘 하나만 신규로 필요.
